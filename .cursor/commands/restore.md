# Session Restore

When I say "restore session" and reference a .mdc file:

1. Read the session spec.
2. Load specs, diffs, and ADRs into working memory.
3. Adopt the prompt_template as the primary instruction set.
4. Confirm readiness and gate.

Respond with:
"Session <ID> restored. Ready to continue."
