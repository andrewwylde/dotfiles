# Manager review checklist

After generating a draft with `career-growth-manager-review`, the manager verifies:

- [ ] All claims are supported by specific evidence
- [ ] Feedback sources are synthesized (not over-indexed on one voice)
- [ ] Level/competency assessments align with calibration discussions
- [ ] Development plan is actionable and prioritized
- [ ] Tone matches the employee's overall standing
- [ ] No surprises -- feedback aligns with ongoing conversations
- [ ] Sensitive topics are handled appropriately
- [ ] Final ratings reflect manager judgment (not AI synthesis)
