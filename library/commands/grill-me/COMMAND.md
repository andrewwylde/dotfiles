# Grill Me

Invoke the `grill-me` skill against the subject in `$ARGUMENTS` (or the plan, spec, or design the user is discussing).

Follow the skill exactly:

- One question at a time; wait for the user's answer before the next question
- Provide your recommended answer with each question
- Explore the codebase when that answers the question instead of asking the user
